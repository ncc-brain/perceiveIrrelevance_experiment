# README

This folder contains pilot data from the cogitate conducted at the MPI by Alex Lepauvre (under Prof. Melloni's supervision) under project **Seattle TWCF Pilot Phase** (project ID: 0232).

This project was initially registered to conduct a pilot of the cogitate first experiment (see [here](https://doi.org/10.1038/s41586-025-08888-1)). It was then extended to conduct additional pilots associated with the cogitate project, hence the subfolders in this folder (each correspond to a specific pilot). 

## Subfolders structures
Each subfolder is organized like so:
- *experiment*: contains the scripts used to run the experiment and that produced the data
- *raw_data*: contains raw data collected from participants, as they come out from the experimental scripts
- *formated_data*: contains raw data that have been organized in a way that is easier to deal with for analysis as well as for potential future reusers of the data to navigate. The structure of these folders is bids-ish
- *derivatives*: data generated from *formated_data* using scripts, contains results of analyses or intermediary steps

In each there may be additional folders (different versions of the experiment for example) and files (reports...)

## Pilots descriptions
- *cog-Experiment1-Pilot-1*: first pilot of the first experiment of the cogitate (investigating the maintenance of conscious content over time) to test how well the original works on 25 participants. The original design was very similar to the final one reported [here](https://doi.org/10.1038/s41586-025-08888-1)
- *cog-Experiment1-Pilot-2-MemoryTask*: second pilot of the first experiment of the cogitate. This was run to investigate whether participants memory of presented stimuli varied as a function of task demands, to address the concern of collaborators that participants might not even consciously experience the task irrelevant stimuli. 
- *cog-Experiment2-Pilot-1-StimuliSelectionTask*: first pilot of the second experiment of the cogitate (video game experiment) with the objective to select stimuli that yields similar visibility performances across stimuli categories. 
- *cog-Experiment2-Pilot-1*: second pilot of the video game. Not run on actual subjects but rather contains data collected on Alex Lepauvre to test the experiment
- *cog-Experiment2-Pilot-3-OlderPopulation*: third pilot of the video game experiment. We ran the experiment on older participants as a proxy for patients with refractory epilepsy. We had the plan of running this experiment on such patients and wanted to test whether they will be able to perform the task by testing older participants. 
- *OLD STUFF*: contains various files and folder, most of them are outdated, but deleting is always risky
